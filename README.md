🏌️‍♂️ Sidcup Family Golf – Website Clone
Club GRADIENT Recruitment Project

A visually rich frontend website clone inspired by the Sidcup Family Golf website.
This project was built as part of my recruitment trial for Club GRADIENT, showcasing my skills in HTML, CSS, JavaScript, and modern UI animation.


📌 Project Overview

This project replicates the design and feel of the Sidcup Family Golf website with:

---Smooth scroll animations

---Custom cursor effects

---Blur follower effect

---Video background hero section

---Interactive hover effects

---Scrolling text marquee

---Modern UI layout

The goal was to recreate a real-world website to understand layout structuring, styling, and animation workflows.

🛠️ Tech Stack

---HTML5 – Structure

---CSS3 – Styling & layout

---JavaScript – Interactivity

---GSAP – Animations

---ScrollTrigger – Scroll-based effects

✨ Key Features

🎯 Custom Cursor
---Cursor smoothly follows mouse using GSAP

---Adds modern interactive feel

---🌫️ Blur Follower Effect
Subtle glow/blur follows the cursor

---Improves visual aesthetics
🎬 Video Background

---Fullscreen looping video hero section
🔄 Infinite Scrolling Text

---CSS animated marquee effect

---💡 Hover Interactions

---Image zoom & glow effects

---Text stroke animations
